# Milestone 5 – Bento mềm (new default look) and Phase 2: brain map timeline and filters, "Học kỳ này", weekly review, scheduled backups + GitHub, phone layout, single `.exe` + tray, Telegram/email reminders

Date: 2026-10-22 → 2026-10-23 · SPEC v1.1 §12 row M5 (built after M6 at the owner's request) + design.md §12 Bento mềm (owner request, 22/10) · Plan: `plans/2026-10-22-m5-bento/plan.md` (acceptance criteria, `rules.md`, briefs, `reports/`)

## What was built
- **Bento mềm, the new default look (F35)** (`web/src/app/{app-layout,bento-frame,calm-frame,bento-top-bar,folder-pane,shell-overlay}.tsx`, `web/src/app/rail/`, `web/src/styles/bento/`, `web/src/features/today/bento/`): Settings → Giao diện → "Phong cách" (Bento mềm / Yên tĩnh) switches at once, without a reload and without a flash after one. A floating 84 px rail (Hôm nay, Việc, Lịch, Não, Hỏi AI, Tài liệu, Thẻ, Nhắc nhở with its badge, then Thư mục and Cài đặt); a 260 px "Thư mục" pane beside it on notes and files in wide windows, a sliding drawer elsewhere; a top bar with "Tìm ghi chú hoặc hỏi AI…" and "Ghi chú mới". Today becomes a 12-column grid of tiles: greeting, date, nearest deadline with a big countdown, the 14-day strip with urgency bars, today's tasks, project rings, "Não hôm nay", quick capture and "7 ngày ghi chép", with one first-paint motion. Every other screen uses the same tiles, radii and tokens. Yên tĩnh is the previous layout, unchanged. Bento tokens for 2 themes × 3 palettes with 330 contrast checks.
- **Today's activity (F35.9)** (`server/src/index/{activity-service,today-activity,today-brain,ai-touched-pages,event-log-reader,event-identities,daily-touches}.ts`): `GET /api/today` gains `activity` (notes created or edited on each of the last 7 days, tasks done yesterday, today's mini map), computed on the server from the index and `events.jsonl`; a new event `note_edited`, at most once per note per local day; one shared, incremental reader of the log.
- **Brain map advanced (F24)** (`server/src/graph/graph-{filter,filter-query,node-facts,history*,intervals}.ts`, `web/src/features/graph/`): a time scrubber week by week with "Phát" (`GET /api/graph/history`; a renamed note keeps its dot); filters by folder, tag and time that dim the rest to 20 % (`GET /api/graph?folder=&tag=&since=`), remembered per vault; notes edited in the last 24 h pulse; "Não hôm nay" on Today (a Bento tile, a small block in calm) opens the map on today's notes.
- **"Học kỳ này" (F25)** (`server/src/semester/`, `web/src/features/semester/`): an opt-in page at the vault root listing courses with their lecture counts and projects grouped by course with deadline, days left and progress; current within 2 s, never written when nothing changed, read-only in the app; it never overwrites an outside edit or a note of hers (`GENERATED_PAGE` on every write path, MCP included).
- **Weekly review (F26)** (`server/src/review/`, `web/src/features/review/`): "Tổng kết tuần" on Sundays (Inbox with "Dọn Inbox", notes and tasks of the week, next week's deadlines), "Để sau" until next Sunday, `#/review` and the palette command any day.
- **Scheduled backups and GitHub (F27)** (`server/src/backup/schedule/`, `server/src/git/git-push.ts`): a daily zip (the same as "Xuất bản sao lưu…") at 21:00 by default into `<home>\Backups` or a chosen folder (USB drives included), caught up after the machine was off, retried after 1 h, keep 14 (only the app's own zips are ever deleted), "Sao lưu ngay", status and "Mở thư mục"; optional push of the version history to a private GitHub repository with the token only in git's environment.
- **Phone-size layout (F28)** (both styles): at 600 px and below a bottom tab bar (Bento) or a sidebar drawer (calm), the right panel as a bottom sheet, full-width palette and capture, 40 px touch targets; no sideways scroll from 360 to 1440 px.
- **Single `.exe`, tray icon and global hotkey (F29)** (`scripts/build-exe.ts`, `scripts/lib/build-exe/`, `server/src/system/`, `launcher/tray/second-brain-tray.ps1`, `launcher/Tạo bản exe.cmd`): `npm run build:exe` makes one Node SEA executable that extracts its runtime once (hash-checked) and runs without a console window; `--stop`, `--login`, `--mcp-stdio`; Desktop and Start-menu shortcuts on the first start; a tray icon (Mở Second Brain / Ghi nhanh / Thoát Second Brain) and Ctrl+Alt+Q for a small capture box from any app; run at login and the Claude Desktop snippet point at the exe.
- **Telegram and email reminders (F31)** (`server/src/reminders/channels/`, `server/src/reminders/notify-outbox*.ts`, `web/src/features/settings/notify-*`): each reminder that fires is also sent once per channel (persisted outbox, backoff, never repeated, dropped when the item is done, moved or deleted); bot token and SMTP password masked and never in logs or backups; "Gửi thử"; consent lines name what is sent and to whom.

18. **Đẩy lên GitHub.**

## Known gaps
- Windows-only behaviour (the exe itself and SmartScreen, the GUI subsystem, message boxes, the tray icon, Ctrl+Alt+Q and its capture box, Desktop/Start-menu/Startup shortcuts, Explorer opening the backup folder, exFAT USB drives, Git Credential Manager staying quiet, real Telegram and Gmail delivery, sleep/wake catch-up) is covered by unit tests, the Linux SEA smoke run and a cross-built structure check, not yet run on Windows – the owner steps above.
- After `#/graph?when=today`, choosing "Não" on the rail keeps "Hôm nay" pressed until a fresh load (visible, not misleading).
- Bento shows as many strip days as fit (≥ 66 px each; 3 on a 360 px phone, 9 at 960 px, 14 at 1440 px) instead of SPEC F10's fixed 7/14; calm keeps F10 (see DECISIONS).
- The first `/api/today` after a start with a very large log (23 MB) waits about 1.2 s while the log is parsed once; the first `GET /api/graph` after an edit is ≈ 190 ms median on the 5k vault (repeated opens 84 ms p95); `GET /api/graph/history` returns several MB on a large log (localhost only).
- The exe embeds the Node it was built with and her `win32-x64` SQLite addon: build it again after a Node upgrade. It is unsigned (SmartScreen). The first Windows start writes about 4,800 files (Defender may make it slower than on Linux). The runtime content check covers the server code and native addons; a damaged dependency or UI file of the same size is not detected.
- In the exe a failed PowerShell toast has no node-notifier fallback (it would flash a console window); the reminder still shows in the app and on Telegram/email when they are on.
- A failed scheduled backup is shown in Settings and the log only (no toast). A scheduled zip needs free space for one zip on the vault drive and one in the target, and saves wait while it is built (as for the manual export). The GitHub push is tested against a local bare repository, not github.com.
- A crash in the middle of a Telegram/email send can lose that one message (it is never sent twice).
- "Học kỳ này": her edit on the same day as the generator's last write counts in Today from the next day; a hand-made note with the page's name that still says `generated: true`, made while the app was closed after she deleted the page, looks like an outside edit of the page.
- The weekly review shows notes created outside the app without `created:` as "đã sửa".
- Phone access over Wi-Fi is not offered (the server listens on 127.0.0.1 only); the phone layout is for narrow windows.
- Brain map fps was measured only with headless software rendering (owner step 24).
