# Milestone 6 – AI: MCP server for Claude Desktop, in-app AI, "AI vừa chạm" on the brain map, PDF text

Date: 2026-10-21 · SPEC v1.1 §12 row M6 (built before M5 at the owner's request, see `DECISIONS.md`) · Plan: `plans/2026-10-21-m6-ai/plan.md` (+ phase briefs, `reports/`)

## What was built
- **PDF text (F30, pulled forward from M5)** (`server/src/sources/`, index schema 6): text of every PDF in `3 Resources` (and PDFs anywhere, for `read_source`) extracted page by page in a background worker thread with size, page, time and memory caps; quality `ok`/`low`/`none` with a reason; derived cache under `.secondbrain/cache/sources/`. PDF pages are searchable (palette shows "tr. N" and opens the viewer at that page); the Documents view says when a PDF has no or little text.
- **MCP server (F32)** (`server/src/mcp/`, `server/src/mcp-stdio.ts`): Streamable HTTP at `/mcp` (Bearer token + Origin + Host) and a thin stdio bridge for Claude Desktop that never runs jobs and starts the server through the launcher when needed. 19 tools (SPEC's list + `write_note`), every write behind one server-enforced permission table (real paths checked, folder links refused), revision-checked writes, bounded results (≤ 60,000 characters per call). Ingest manifest per source: begin/complete/fail, idempotent completion, the server writes the `wiki/log.md` line and broadcasts `ai:touched`; `wiki_lint`; resources and prompts from the vault's `CLAUDE.md`. Settings shows the Claude Desktop snippet with a copy button and the switch "Cho phép AI sửa ghi chú cá nhân".
- **In-app AI (F33)** (`server/src/ai/`, `web/src/features/{ai-chat,ai-actions,ai-inbox,settings}/`): Anthropic, OpenAI or Gemini through `fetch` with the owner's API key; nothing is sent before she agrees in a consent dialog that names the provider and what is sent; folder scope; monthly token limit with reservations; status everywhere. Chat "Hỏi" (Ask screen, note panel, palette): deadline questions answered from the Today service (the server writes the list, the model only an intro), text questions from 12 retrieved chunks (BM25 + embeddings when on) with validated `[[ ]]` citations; "Lưu thành ghi chú". Editor "AI" menu (`Alt+A`): summarize, rewrite, explain, suggest links, suggest tags – proposals she accepts. Inbox tidying: folder + clearer title proposals applied through the journaled rename with undo. Today assistant line. Search by meaning (embeddings, separate consent, 5-minute quiet period per note, backoff, rebuild on model change).
- **"AI vừa chạm" (F34)** (`web/src/features/graph/graph-ai-touch*`): after an ingest the source appears at the map's edge and a signal reaches each updated page in order (150 ms apart, lit 10 s); an accessible "AI vừa cập nhật" list in the side panel; static under reduced motion.
- **Owner requests**: richer paper format (Bài toán with Input/Output, Các cách hiện có, Khoảng trống và động lực, Dữ liệu, Thí nghiệm, Hạn chế…) in `Templates/Paper.md` and in the `CLAUDE.md` page format, with "Cập nhật mẫu" that replaces only unedited old versions (old copy to the trash); "AI proposes, you accept" everywhere; bounded MCP results so a growing vault never floods Claude's context.

## Independent review
Two read-only reviewers plus the e2e run. **A – security, privacy, data safety** (1 High, 5 Medium, 4 Low): MCP writes through a folder link inside `wiki/` reached `CLAUDE.md`, raw sources and personal notes; concurrent requests passed the monthly cap; a small deflate-bomb PDF used gigabytes of memory; quadratic HTML stripping; an escaped `\[[…]]` slipped past citation checks; hidden folders were in the default AI scope; a possible duplicate ingest log line; control characters in log lines; Today-line counts and usage across a vault switch – all fixed with regression tests. **B – UI, spec, accessibility in a real browser** (1 High, 3 Medium, 10 Low): S5 with a course filter answered "none" for a task naming the course in plain words; "sent to" copy did not name the embedding provider; a focus trap leak in the Inbox dialog; "AI chưa bật" shown when only a re-consent was needed; copy, styling and layout details – all fixed. The e2e run added two defects (ghost source dot over the legend, one-note dialog copy) and four observations (relevance floor, slide-deck wording, bridge port, paper → PDF edge) – all fixed. Reports: `plans/2026-10-21-m6-ai/reports/review-a-security-privacy.md`, `review-b-ui-spec.md`, `x-e2e-report.md`, fix reports `fs-security-fixes-report.md`, `fa-server-fixes-report.md`, `fb-web-fixes-report.md`.

## Manual checks for the owner (Windows)
1. Close the running app (`D:\SECONDBRAIN\Mở Second Brain.cmd stop`), then double-click `Mở Second Brain.cmd`. The first start after this update installs a few libraries, rebuilds the app and rebuilds the search index once (PDF text is new) – a few minutes. The app opens with your notes.
2. **Templates (owner request):** Cài đặt → Kho ghi chú → "Cập nhật mẫu" (shown only when your `Paper.md`/`CLAUDE.md` are unedited old versions). Create a note from the Paper template: the new sections are there.
3. **PDF text:** open "Tài liệu": your PDFs show nothing special when their text was read, "Không đọc được chữ" for scans. `Ctrl+K`, type a word from inside a PDF: the result says "tr. N" and opens at that page.
4. **Claude Desktop (F32.1):** Cài đặt → Kết nối Claude (MCP) → "Sao chép"; in Claude Desktop → Settings → Developer → Edit Config, paste it into `claude_desktop_config.json` (merge with what is there), save, restart Claude Desktop. In a new chat the tools of "second-brain" are listed. Ask "Hôm nay mình có gì?" – Claude answers from your Today.
5. **One real ingest (F32.6, S4):** put one real paper PDF in `3 Resources/papers/`, open the brain map in the app, and in Claude Desktop say "Nạp paper mới theo CLAUDE.md". Watch the map: the paper appears at the edge and the updated pages light up; the side panel lists them.
6. Open the paper page Claude wrote in `wiki/papers/`: check 3 claims against the PDF pages it cites (tr. N), check that "Nhận xét của AI" is separate and the research-gap page says "Trong N nguồn đã đọc, chưa thấy…". `wiki/log.md` has one new line.
7. **A real API key (S5):** Cài đặt → AI: choose the provider, paste the key ("Lưu khóa"), switch "Bật AI trong app" on and read the consent dialog, "Đồng ý và bật". Ask "Hỏi AI": "Tuần này có gì đến hạn?" – the list equals Today's; "Tuần này môn <một môn của bạn> có gì đến hạn?"; a question about your notes – links open the right notes. Try the editor: select a paragraph, `Alt+A` → "Tóm tắt" → "Chèn bên dưới"; then `Ctrl+Z`. The usage line in Settings counts tokens.
8. **Search by meaning (optional, costs a little):** switch "Tìm theo nghĩa" on (OpenAI or Gemini key), wait for "Sẵn sàng", then `Ctrl+K` with a phrase that is not literally in your notes.
9. `Alt+A` works in Chrome, Edge and the installed app window.

## Known gaps
- Real-provider checks (model defaults, Gemini 3.x behaviour, token counts, the 0.25 relevance floor for Gemini embeddings) need the owner's keys (steps 7–8).
- The HTTP snippet may not be accepted by Claude Desktop (stdio is the guaranteed path, SPEC §13); on Windows the bridge starts the server through the launcher, which uses the default home.
- The token estimate for the cap is characters/4; Vietnamese runs ~2–3 characters per token, so one admitted request may overrun the cap a little (the recorded usage is the provider's).
- PDF extraction runs in a worker thread: after many hostile PDFs the process keeps some freed memory on Linux (Windows untested); a child process would isolate it fully.
- Topic matching by title words can over-match very short titles; a Daily note that links a course counts for all its tasks.
- "Não hôm nay" (count of AI-touched pages on Today) comes with the Phase 2 widget (M5).
